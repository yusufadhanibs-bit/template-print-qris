# Template Print QRIS - Merchandise

Alat cetak QRIS berbasis browser (tanpa Adobe) untuk:

- **SoundBox**: Front (Stiker) & Back (AP)
- **Akrilik A5** dan **Akrilik A6**
- **Stiker Thermal**: A4 / A3+ dengan garis potong (cutting sticker)

## Cara pakai
Buka halaman GitHub Pages repo ini, pilih menu, upload PNG QRIS, lalu download hasilnya.
File QRIS hanya diproses di browser pengguna dan tidak dikirim ke server mana pun.

## Cara memperbarui
1. Ganti nama file template terbaru menjadi `index.html`.
2. Di halaman repo: **Add file → Upload files**, seret `index.html`, lalu **Commit changes**.
3. Tunggu ± 1 menit, lalu muat ulang halaman (Ctrl+F5).
